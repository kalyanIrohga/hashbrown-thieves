【给我的好貂貂做的好朋友小游戏，希望天天开心，经常能吃到美味的薯饼，】

一只身手灵活的鼬，带着一只行动不太利索的小熊，溜进了农夫家。目标很明确，夺取厨房里那口热乎酥脆的薯饼！

不过，偷吃也得讲配合。你要帮这两个小家伙一路过关；而至于小熊，你得狠狠殴打他，他才知道该行动了。
总共四关，最后还有一块超大薯饼等着它们。


目前已经可以从头玩到通关，电脑上用鼠标点，手机上直接戳就行。现在是中文版，英文版之后会补上。

玩法、角色和关卡都是我自己设计的，程序部分用 p5.js，和 Codex、Claude 一起完成，部署在 GitHub Pages 上。
最近正在整理美术设计文件、制作 Rive 动画。
